class Stack:
    def __init__(self):
        self._items = []

Step 2 · stacks.py

    def addTop(self, item):
        self._items.append(item)

Step 3 · stacks.py

    def removeTop(self):
        if not self._items:
            raise Exception("Stack is empty")
        return self._items.pop()

Step 4 · stacks.py

    def peek(self):
        if not self._items:
            raise Exception("Stack is empty")
        return self._items[-1]

Step 5 · undo.py

3 · A queue: first in, first out (FIFO) Like a coffee shop line: join at the back, get served from the front. Nobody skips. front ← Maria[0] Sam[1] Alex[2] ← back addRight joins at the back (right) · removeLeft serves the front (index 0) Task scheduling and request handling (in the order they arrive) Message brokers (messages wait their turn) · Breadth-first search A queue is fair: the oldest item always goes next. The plan: What a queue is: add at the back, take from the front, so the oldest item always goes next. Point at the boxes: "This is the Python list inside our Queue. Index 0, Maria, is the front of the line. New people join on the right." Common words: enqueue (join the line) and dequeue (leave the front). The curriculum calls them addRight and removeLeft; the homework uses enqueue and dequeue. Breadth-first search comes back in a future lecture (trees). Just name it. class Queue:

Step 3 · queues.py

    def removeLeft(self):
        if not self._items:

Step 4 · queues.py

    def peek(self):
        if not self._items:
            raise Exception("Queue is empty")

4 · pop(0) is slow: everyone shifts left before Maria[0] Sam[1] Alex[2] Jo[3] ← ← ← every item moves one seat after Sam[0] Alex[1] Jo[2] pop() takes the last item: nothing moves, O(1) pop(0) takes the first item: n − 1 items move, O(n) We use pop(0) on purpose: it keeps the queue easy to read. Real code uses collections.deque and popleft(): O(1) Same answer, different cost. Fine for 10 people, slow for a million. The plan: Why pop(0) is slow: removing the first item makes every other item move one seat. We keep it anyway, to keep the class simple. Point at the red box: "Maria leaves. A Python list has no empty seats, so Sam, Alex and Jo each move left. With a million people, that's a million moves to serve one person." callitems that moveBig-O append(x)noneO(1) pop()noneO(1) pop(0)all the othersO(n) deque.popleft()noneO(1) Say: "We keep pop(0) today and in the homework so the class reads like the picture. Just know it's O(n). If you ever need a real queue in Python, use deque." Students may use either in the homework. A deque ("deck") is a double-ended queue: fast to add or remove at both ends. How slow is pop(0)? Time it

Empty a long line with pop(0), then with a deque, and time both. Your seconds will differ; the pattern (double the people, about 4 times the time for pop(0)) stays.

New file: speed.py (same folder)

Step 1 · speed.py

import time
from collections import deque

for n in [25_000, 50_000, 100_000]:
    line = list(range(n))
    start = time.perf_counter()
    while line:
        line.pop(0)
    slow = time.perf_counter() - start

Step 2 · speed.py

    line = deque(range(n))
    start = time.perf_counter()
    while line:
        line.popleft()
    fast = time.perf_counter() - start
    print(f"{n:>7} people   pop(0): {slow:.3f}s   popleft: {fast:.3f}s")
